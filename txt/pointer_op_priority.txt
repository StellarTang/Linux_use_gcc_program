C语言 指针相关运算符优先级 + 指针运算总结
=============================================
优先级从高到低；结合性标注

【1 最高优先级：后缀运算符】 结合性：左到右
[]      数组下标
()      函数调用
->      指针访问结构体成员
.       结构体成员访问
重点：后缀运算符 > 一元*、&
例子：*p[1] 等价 *(p[1])，不是 (*p)[1]

【2 一元运算符】 结合性：右到左（非常关键！）
*       解引用
&       取地址
++      前置自增 ++p
--      前置自减 --p
!       逻辑非
sizeof  求大小
正负号 + -
例子：
&test_a + 1   → (&test_a) + 1
*&test_a      → *(&test_a)

【3 乘除模】 左到右
* / %

【4 二元加减（指针加减在这里！）】 左到右
+   -
规则：指针 ± 整数；两个指针只能相减，禁止指针+指针

【5 关系比较】左到右
<  <=  >  >=

【6 相等判断】左到右
==  !=

【7 逻辑与 &&】左到右

【8 逻辑或 ||】左到右

【9 赋值运算符 最低优先级】右到左
=  +=  -=  *=  /=

====================
指针运算4条核心规则
====================
1. 指针 ± 整数：移动N个【指针指向的对象】，不是N个字节
例：
int (*p)[100];
p +1  移动 1 * sizeof(int[100]) = 400字节（int占4字节）
int *q;
q +1  移动 1 * sizeof(int) = 4字节

2. 同类型指针相减 ptr1 - ptr2
结果 = 两者相差【对象个数】，不是字节差
不同类型指针不能直接相减，需要强制类型转换

3. 同类型指针支持比较：> < >= <= == !=
多用于数组边界判断

4. 禁止操作：指针 + 指针、指针 * / 数字，行为未定义

====================
数组名退化 + &/* 搭配重点
====================
int test_a[5][100];
test_a +1        // test_a退化 → &test_a[0]，行指针+1，跳1行（400字节）
&test_a +1       // &test_a不退化，取整个数组地址；+1跳过整个二维数组（2000字节）
*&test_a +1      // *&test_a等价test_a，等于test_a+1，跳1行

表达式例子：
*(test_a + 3) + 5 → 等价 &test_a[3][5]，类型 int*
*(*(test_a + 3)+5) → test_a[3][5]，取元素值

====================
高频易错例子
====================
*p++      → *(p++)  后缀++优先级高于*，先p自增，再解引用
(*p)++    → 解引用，把p指向的值+1，指针本身不变
*++p      → *(++p)  指针先自增，再解引用

记忆口诀：
后缀[]最高；一元& * 右结合；一元高于加减；指针加减按【对象长度】偏移，不是字节。
